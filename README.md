# claude-memory

A Claude code hook that reads interactions between the user and AI agent, learns the user's communication style and preferences using an OpenAI-compatible LLM, and maintains a personalized `CLAUDE.md` file.

## Features

- 🎯 **Interaction Analysis**: Automatically analyzes user-agent conversations to extract insights
- 🧠 **Style Learning**: Uses OpenAI-compatible LLMs to understand communication patterns
- 📝 **Preference Tracking**: Maintains a structured `CLAUDE.md` file with learned preferences
- 🔄 **Smart Merging**: Intelligently merges new insights with existing preferences
- ⚙️ **Configurable**: Supports any OpenAI-compatible API endpoint

## Installation

```bash
npm install claude-memory
```

## Quick Start

```typescript
import { createHook, Interaction } from 'claude-memory';

// Configure the hook
const hook = createHook({
  apiKey: process.env.OPENAI_API_KEY || '',
  model: 'gpt-3.5-turbo',
  claudeFilePath: './CLAUDE.md',
  maxMessages: 20,
});

// Example interaction
const interaction: Interaction = {
  messages: [
    { role: 'user', content: 'Can you help me understand async/await in TypeScript?' },
    { role: 'assistant', content: 'Of course! Async/await is a way to handle asynchronous operations...' },
    { role: 'user', content: 'Thanks! I prefer concise examples with code.' },
    { role: 'assistant', content: 'Here\'s a concise example:\n```typescript\nasync function fetchData() { ... }```' },
  ],
};

// Process the interaction
await hook.processInteraction(interaction);

// The CLAUDE.md file is now updated with learned preferences
console.log(await hook.getCurrentPreferences());
```

## Configuration

### ClaudeMemoryConfig

| Option | Type | Default | Description |
|--------|------|---------|-------------|
| `apiKey` | `string` | *required* | API key for OpenAI-compatible service |
| `apiEndpoint` | `string` | OpenAI default | Custom API endpoint (e.g., for local LLMs) |
| `model` | `string` | `'gpt-3.5-turbo'` | Model to use for analysis |
| `claudeFilePath` | `string` | `'./CLAUDE.md'` | Path to the preferences file |
| `maxMessages` | `number` | `20` | Maximum messages to analyze per interaction |

## Using with Different LLM Providers

### OpenAI

```typescript
const hook = createHook({
  apiKey: process.env.OPENAI_API_KEY || '',
  model: 'gpt-4',
});
```

### Azure OpenAI

```typescript
const hook = createHook({
  apiKey: process.env.AZURE_OPENAI_KEY || '',
  apiEndpoint: 'https://your-resource.openai.azure.com/openai/deployments/your-deployment',
  model: 'gpt-4',
});
```

### Local LLM (e.g., LM Studio, Ollama)

```typescript
const hook = createHook({
  apiKey: 'not-needed', // Some local servers still require this
  apiEndpoint: 'http://localhost:1234/v1',
  model: 'local-model',
});
```

## API Reference

### ClaudeMemoryHook

Main class for processing interactions and managing preferences.

#### Methods

##### `processInteraction(interaction: Interaction): Promise<void>`

Analyzes an interaction and updates the CLAUDE.md file.

##### `getCurrentPreferences(): Promise<string>`

Returns the current content of the CLAUDE.md file.

### Types

```typescript
interface Message {
  role: 'user' | 'assistant' | 'system';
  content: string;
  timestamp?: Date;
}

interface Interaction {
  messages: Message[];
  sessionId?: string;
  metadata?: Record<string, unknown>;
}

interface UserPreferences {
  communicationStyle?: string;
  topicPreferences?: string[];
  technicalLevel?: string;
  formatPreferences?: string;
  languageStyle?: string;
  otherInsights?: string[];
}
```
